# Vercel Drop, no account needed: Quollridge Energy walkthrough

A story-first, fully simulated sales walkthrough. A storm knocks out power for 38,400 customers at a fictional ANZ energy retailer. An AI agent builds the outage status page in six minutes. Before, it stalls at sign-up and an IT ticket and goes live 4h 12m later. With Vercel Drop it is live in 38 seconds, then claimed into the company's Vercel team within the hour, while an unclaimed draft expires on its own.

- Live: https://vercel-drop-walkthrough.vercel.app
- `TALK_TRACK.md`: 2 to 3 minute spoken script with click cues
- `LINKEDIN_CAPTION.md`: post copy

Everything runs client-side. No API keys, no secrets. All numbers are illustrative.

Product background: https://vercel.com/drop and https://vercel.com/docs/drop

```bash
npm install
npm run dev
```
